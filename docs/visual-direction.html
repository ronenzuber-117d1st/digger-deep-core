DEEP CORE - visual direction

Pixel-art roguelite reimagining of Digger. 480x272 internal, 16x16 tiles (30x17), 32-colour palette only, nearest-neighbour scaling. Every sprite, tile, icon and glyph here is original; the Digger screenshots informed readability principles only (strong silhouettes, tunnel vs dirt contrast, pickups that pop, a minimal score strip).

Note: only the screenshots and the palette arrived with the brief - no game design doc came through. Where it would matter (upgrade names, biome name, run stats) I used your brief; send the doc and I will reconcile.

1. Two art directions for the dive screen

Same level, same sprites, same HUD layout. Topsoil, floor 3. Only light, tile treatment and palette roles differ.

A - "Ember Hearth" (cosy, warm, flat-lit)

Dirt is mid brown with a lit top-left lip; tunnels are deep indigo (not black) so outlines and monsters keep a dark edge. Everything is readable everywhere at a glance. Danger comes from shape and from red/pink being reserved for harm.

B - "Lantern Dark" (moody, contrasty, light-driven)

Near-black voids, darker dirt, and a dithered lantern cone around the rig. Pickups stay fully lit and gain a faint green halo. Atmospheric, but monsters and tunnels outside the cone vanish, which fights the "whole screen is the playfield" goal at 480x272.

Pick: A, with B's lantern kept as a mechanic

A best fits "cosy but dangerous, charming not grim" and keeps every tile legible. B is not wasted: the lantern dither is the visual for deeper biomes and for the Lantern Mount upgrade (more light = more of the dark biome revealed). Everything below is built in A.

Chosen direction, second state: gold bag lands on a Grub

Bag crushes the Grub (squashed pose), nuggets spill and bounce, impact starburst and +250 popup. HUD occupies only the top bedrock row; playfield is the full 28x15 interior.

2. Sprite concept sheet

Each strip: actual size (1x) on the left of the pair, 4x below. All sprites are generated as shapes then lit from the top-left with a 1px ink outline, so light direction is consistent even for mirrored or rotated variants.

Top row solid black: rig (drill nose), Grub (low horizontal segmented bar), Burrower (Y-shaped claws, pointed snout), Spitter (round body + barrel), Drifter (dome + tendrils, hollow), bag, emerald, fuel can, nest. All distinct. Below: same sprites in colour.

Tile set: Topsoil

Row 1: dirt x4, tunnel floor (plain / with N+W cast shadow), bedrock x3. Row 2: edges N E S W, convex corners, concave corners. Row 3: corridors, caps, island. Edge rule: 1px dark outline, then 1px lit lip on N/W faces or shade on S/E faces. Tunnel tiles add a 2px N and 1px W shadow.

4. Run-pick screen

Three cards over a heavily dimmed dive screen; HUD stays visible. Rarity is shown by text tag and by filled diamonds (shape, not colour). Selected card lifts 4px, gets an amber frame and a hover-state button. Effect text area holds 6 lines; current copy uses 3, so +30% length still fits.

5. Summary screen and dialogue box

Dialogue box style (three speakers)

Plate with a 28px portrait well, a name tab that carries the speaker colour (amber Tessa, green Orin, purple Static), a 3-line text area and a bobbing continue arrow. Static's box adds flickering purple noise pixels along the top and bottom edge - the hum.

6. Style guide

Pixel font: "Coalface 5x7" (original)

5x7 glyph, 6px advance, 9px line pitch, caps and digits only, bold = double-strike (7px advance). Chosen so ~30 chars/line at 180px panels and 55+ at full width stay readable at 1x and integer scales. Hebrew: extend the same 5x7 grid with 22 letters plus finals; the layout slots already reserve +30%. If you prefer a third-party face, an OFL pixel font is the fallback, but it would not match these 8px rules exactly.

HUD components

HUD lives in the top bedrock row (16px). Hearts = HP; blue bar = fuel (16 segments, ticks at 25/50/75%); emerald count; floor; biome name (right-aligned, 134px slot = ~15 chars after +30%). Low fuel switches to orange/red, flashes between two frames and adds the word LOW! so it is not colour-only.

Buttons: normal, hover, pressed, disabled

Hover: brighter face plus a small left arrow cue. Pressed: darker face, highlight only top-left, label drops 1px. Disabled: purple-grey face, muted label, no highlight.

Icons

Left to right: Hull, Fuel Tank, Drill Motor, Pulse Core, Prospector, Salvage Contract, Extra Pick, Lantern Mount, Magnet Coil, Echo Ping. Rules: 16x16 canvas with 1px margin, 1px ink outline, 3-step ramp (light, mid, shade) lit top-left, one white or cream specular dot at most, one hero colour per icon, no text inside icons.

Technical rules

  • Internal 480x272, scale by integers only (2x = 960x544, 4x = 1920x1088, letterbox or crop 8px for 1080p).
  • All coordinates integers; no sub-pixel movement of art, no alpha, no blur. Dither (Bayer 4x4) is used only for the lantern and dimming.
  • HUD is 1 tile tall, in the bedrock border; nothing covers the 28x15 playfield.
  • Text slots reserve +30%; toggle the checkbox above to see the marks. Palette check below is computed from the actual canvases.
